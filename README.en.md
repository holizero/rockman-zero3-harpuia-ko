# Rockman Zero 3 · Harpuia Korean Mod

[한국어](./README.md)

A fan mod that brings playable Harpuia to Rockman Zero 3. It applies the Korean translation, title screen, and mod to the Japanese base ROM in one step.

## Blog guide

**[Introduction · Installation · Skill guide](https://mntkim.com/?page_id=13039)**

Read the blog before installing. It covers patching and restoration, controls and gameplay GIFs, saves, and troubleshooting. The game text and patcher interface are in Korean.

The blog guide is currently available in Korean.

## Before you start

- This is a patch package for the Japanese base ROM. No game ROMs, saves, or emulators are included.
- Download the release ZIP. GitHub’s automatic `Source code (zip)` is not the patch package.
- Back up your original ROM and saves. See the blog for supported inputs and precautions.
